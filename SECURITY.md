# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/Occtoo/dotnet-sdk/security/advisories/new)
— never in a public issue, discussion, or pull request. Include the affected
version, a description, and reproduction steps if you have them.

You will get an acknowledgement within five business days. Please give us the
chance to release a fix before disclosing publicly.

## Supported versions

Until `1.0`, only the latest released version receives security fixes.

## Scope

This policy covers the `Occtoo.Sdk` package and this repository. Issues in the
Occtoo platform itself belong with [Occtoo support](https://www.occtoo.com/contact).
